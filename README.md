# Udara Dewshan - Portfolio Website

A modern, responsive portfolio website showcasing my skills, education, projects, and experience as a trainee software engineer.

## 🌟 Features

- **Modern UI/UX Design**: Clean and professional interface with gradient backgrounds and smooth animations
- **Responsive Layout**: Fully responsive across all device sizes
- **Interactive Elements**: 
  - Animated gradient backgrounds
  - Typing effect for hero section
  - Live clock display
  - Hover animations on cards and buttons
  - Scroll-spy navigation
- **Project Showcase**: Dedicated projects page with grid layout
- **Contact Form**: Functional contact section with Google Maps integration
- **Social Media Integration**: Links to GitHub, LinkedIn, and Instagram

## 🛠️ Technologies Used

### Frontend
- **HTML5**: Semantic markup
- **CSS3**: 
  - Custom animations with `@keyframes`
  - CSS Grid and Flexbox layouts
  - Gradient backgrounds
  - Responsive design
- **JavaScript**: 
  - Typed.js for typing animation
  - AOS (Animate On Scroll) library
  - Live clock functionality
- **Bootstrap 5**: Responsive framework
- **Font Awesome 6**: Icons

### Libraries & Tools
- [Bootstrap 5.3.2](https://getbootstrap.com/)
- [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- [Typed.js](https://github.com/mattboldt/typed.js/)
- [Google Maps Embed API](https://developers.google.com/maps/documentation/embed/get-started)
